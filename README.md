# 🚗 Rent-A-Car Management System

A modern, high-performance full-stack car rental platform. Built with a focus on speed, optimal state management, and a clean SaaS user interface.

## 💻 Tech Stack

**Frontend**
* React 18 (Vite)
* TypeScript
* Tailwind CSS
* TanStack React Query
* Axios & React Router DOM

**Backend**
* Java 17+
* Spring Boot 3
* Spring Data JPA / Hibernate
* Spring Security
* Maven

## 🚀 Quick Start

**Run the Project (Spring Boot & React)**
```bash
1. Run the Backend (Spring Boot)
# Navigate to the backend directory
cd backend

# Run the Spring Boot application
./mvnw spring-boot:run

2. Run the Frontend (React)
# Navigate to the frontend directory
cd rent-a-car-frontend

# Install dependencies
npm install

# Start the development server
npm run dev


Note: Make sure to update your database credentials in the application.properties file before running the backend.
